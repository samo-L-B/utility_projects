0.  Abstract:
    This project focused on converting text input to audio output. Therefore first we have initiated 3 different methods:

    0.1. (DE/EN/ES/FR/IT/PT)-py-to-speech.py

          Convert text input from python file to speech output (wav file):
          -> in folder 0.1-py-to-speech
          -> subfolder output_inline
          -> OUTPUT: subfolder (DE/EN/ES/FR/IT/PT)

    0.2. (DE/EN/ES/FR/IT/PT)-cd-to-speech.py

          Convert text input from command line to speech output (wav file):
          -> in folder 0.2-cd-to-speech
          -> in folder ouput_command # optional: -> OUTPUT: subfolder (DE/EN/ES/FR/IT/PT)

    0.3. (DE/EN/ES/FR/IT/PT)-txt-to-speech.py

          Convert text input txt file (folder txt_input) to speech output (wav file):
          -> in folder 0.3-txt-to-speech
          -> in subfolder output_txt (other )
                 # optional: -> subfolder language (DE/EN/ES/FR/IT/PT)

1.  Problem Statement:

    Improve workflow, increase productivity and prevention worst-case scenario x. Therefore, the problem was identified in converting text output to audio output files which can be stored offline. Additionally, audiobooks can be created easiliy with the code.

2.  Outlook & Future Research:
