# utility_projects

Small standalone tools, collected in one repo (2026-11-05). Each folder was its own repo; its history is kept here.

| Folder | Was | What it does |
|---|---|---|
| [`yt/`](yt/) | `project-yt` | YouTube downloader (2024). For real downloads use [yt-dlp](https://github.com/yt-dlp/yt-dlp), installed system-wide (`pacman -S yt-dlp`). |
| [`tts/`](tts/) | `project-tts` | Three text-to-speech approaches (2024). |
| [`musica/`](musica/) | `project-musica` | Music gems from curated lists (Rolling Stone 500). SELF-Luh's `l` reads `musica/rolling_stone_top_500_records/` for its daily record. |
